# Financeiro Web

Interface Next.js independente do Financeiro. Ela não contém handlers de API, Prisma, banco de dados ou segredos de autenticação.

## Executar localmente

1. Copie `.env.example` para `.env.local` e informe a URL do `financeiro-api`.
2. Execute `npm install`.
3. Execute `npm run dev`.

Por padrão, a API local fica em `http://localhost:3001`.
