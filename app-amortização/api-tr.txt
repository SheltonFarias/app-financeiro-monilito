# Integração da API de TR (Taxa Referencial) do Banco Central com JavaScript e TypeScript

## Introdução

A **Taxa Referencial (TR)** é disponibilizada pelo Banco Central do Brasil através do **SGS (Sistema Gerenciador de Séries Temporais)**.

A API é:

* Gratuita
* Pública
* Não necessita autenticação
* Utiliza HTTPS
* Retorna JSON
* Pode ser consumida diretamente por aplicações JavaScript e TypeScript

---

# Endpoint

A TR Mensal possui o código **226**.

```
GET https://api.bcb.gov.br/dados/serie/bcdata.sgs.226/dados
```

---

# Parâmetros

| Parâmetro   | Obrigatório | Descrição                    |
| ----------- | ----------- | ---------------------------- |
| formato     | Sim         | Formato da resposta (`json`) |
| dataInicial | Não         | Data inicial (`dd/MM/yyyy`)  |
| dataFinal   | Não         | Data final (`dd/MM/yyyy`)    |

Exemplo:

```
https://api.bcb.gov.br/dados/serie/bcdata.sgs.226/dados?formato=json&dataInicial=01/01/2025&dataFinal=31/12/2025
```

---

# Resposta

A API retorna um array de objetos.

```json
[
    {
        "data": "01/01/2025",
        "dataFim": "31/01/2025",
        "valor": "0.1704"
    },
    {
        "data": "01/02/2025",
        "dataFim": "28/02/2025",
        "valor": "0.1682"
    }
]
```

## Campos

| Campo   | Tipo   | Descrição         |
| ------- | ------ | ----------------- |
| data    | string | Início do período |
| dataFim | string | Fim do período    |
| valor   | string | Valor da TR       |

> **Importante:** o campo `valor` é retornado como **string**. Recomenda-se convertê-lo para `number` antes de utilizá-lo em cálculos.

# Definindo a interface (TypeScript)

```ts
export interface TRResponse {
    data: string;
    dataFim: string;
    valor: string;
}
```

Caso deseje trabalhar com valores numéricos dentro da aplicação, pode criar outro tipo:

```ts
export interface TR {
    data: Date;
    dataFim: Date;
    valor: number;
}
```

---

# Criando o serviço

```ts
const BASE_URL =
    "https://api.bcb.gov.br/dados/serie/bcdata.sgs.226/dados";
```

---

## Buscando toda a série

```ts
export async function getTR() {
    const response = await fetch(
        `${BASE_URL}?formato=json`
    );

    if (!response.ok) {
        throw new Error("Erro ao consultar o Banco Central.");
    }

    return response.json();
}
```

---

## Buscando um período

```ts
export async function getTRByPeriod(
    dataInicial: string,
    dataFinal: string
) {
    const response = await fetch(
        `${BASE_URL}?formato=json&dataInicial=${dataInicial}&dataFinal=${dataFinal}`
    );

    if (!response.ok) {
        throw new Error("Erro ao consultar a TR.");
    }

    return response.json();
}
```

Uso:

```ts
const taxas = await getTRByPeriod(
    "01/01/2025",
    "31/12/2025"
);

console.log(taxas);
```

---

# Convertendo os valores

Como o Banco Central retorna strings, normalmente convertemos os dados para um modelo interno.

```ts
import { TRResponse } from "../types/tr";

export function mapTR(data: TRResponse[]) {
    return data.map(item => ({
        data: new Date(item.data.split("/").reverse().join("-")),
        dataFim: new Date(item.dataFim.split("/").reverse().join("-")),
        valor: Number(item.valor)
    }));
}
```

Resultado:

```ts
[
    {
        data: Date,
        dataFim: Date,
        valor: 0.1704
    }
]
```

---

# Tratamento de erros

Sempre envolva chamadas HTTP com `try/catch`.

```ts
try {

    const tr = await getTR();

    console.log(tr);

} catch (error) {

    console.error(error);

}
```

Também é recomendável tratar:

* Timeout
* Erro de rede
* JSON inválido
* API indisponível
* Resposta vazia

# Criando um Service completo

```ts
import { TRResponse } from "../types/tr";

export class TRService {

    private readonly baseUrl =
        "https://api.bcb.gov.br/dados/serie/bcdata.sgs.226/dados";

    async findAll(): Promise<TRResponse[]> {

        const response = await fetch(
            `${this.baseUrl}?formato=json`
        );

        if (!response.ok) {
            throw new Error("Erro ao consultar TR.");
        }

        return response.json();
    }

    async findByPeriod(
        inicio: string,
        fim: string
    ): Promise<TRResponse[]> {

        const response = await fetch(
            `${this.baseUrl}?formato=json&dataInicial=${inicio}&dataFinal=${fim}`
        );

        if (!response.ok) {
            throw new Error("Erro ao consultar período.");
        }

        return response.json();
    }

}
```

Uso:

```ts
const service = new TRService();

const tr = await service.findByPeriod(
    "01/01/2025",
    "31/12/2025"
);
```

# Boas práticas

## Não consulte a API a cada requisição

A TR é atualizada apenas uma vez por mês. O ideal é:

```
Job Agendado
        │
        ▼
Banco Central
        │
        ▼
Banco da Aplicação
        │
        ▼
Sistema
```

Assim:

* reduz chamadas externas;
* melhora a performance;
* evita indisponibilidade da API do Banco Central.

---

## Crie uma camada de abstração

Evite utilizar `fetch()` diretamente em várias partes da aplicação.

Prefira uma única classe ou módulo responsável pela integração.

```
Controllers

↓

Services

↓

TRService

↓

Banco Central
```

Caso a API mude no futuro, apenas essa camada precisará ser alterada.

---

## Cache

Como os dados históricos da TR não mudam, implemente cache para consultas repetidas. Em aplicações Node.js, você pode utilizar soluções como Redis ou um cache em memória, dependendo da necessidade.

---

## Persistência

Se o sistema realiza cálculos financeiros com frequência, armazene a TR em banco de dados e sincronize periodicamente.

Fluxo recomendado:

```
Scheduler

↓

Consulta API

↓

Validação

↓

Banco

↓

Sistema
```
